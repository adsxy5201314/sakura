这篇是写给自己的说明书，看完就可以删掉。

## 第一步：新建文章文件

在 `blog/posts/` 文件夹里新建一个 `.md` 文件，文件名用英文或数字，比如 `my-trip.md`。

文章用 **Markdown** 格式写，常用写法：

| 想要的效果 | 写法 |
| --- | --- |
| 小标题 | `## 标题` |
| 加粗 | `**文字**` |
| 链接 | `[文字](网址)` |
| 图片 | `![说明](图片地址)` |
| 列表 | 每行开头写 `- ` |
| 引用 | 行首写 `> ` |

## 第二步：登记到文章列表

打开 `blog/posts.json`，在最前面加一段：

```json
{
  "slug": "my-trip",
  "title": "文章标题",
  "date": "2026-11-05",
  "summary": "一两句话的摘要",
  "tags": ["旅行"]
}
```

`slug` 要和文件名一样（不带 `.md`）。如果想先写着不公开，加一行 `"draft": true`。

## 第三步：提交

把改动提交到 GitHub，网站就会自动更新。也可以直接告诉 Claude 你想写什么，让它帮你加。
